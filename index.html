AI PAGE ASSIST

A dark-blue, minimal AI overlay you can inject into any website with one fetch() command. It sees your current tab and answers using GPT-4o / GPT-5.

⚡ One-line Console Loader

fetch('https://raw.githubusercontent.com/YOUR_USERNAME/ai-page-assistant/main/ai-overlay.js') .then(res => res.text()) .then(code => eval(code)); Get Bookmarklet →

✨ What it does

• Analyze any page you are on
• Summarize articles in 5 bullets
• Ask "what's the price?" "is this legit?"
• Extract all visible text
• Draggable, dark-blue UI

🔒 Setup

1. Upload ai-overlay.js to this repo
2. Get OpenAI API key at platform.openai.com
3. Paste key in the overlay (saved locally)
4. Model: gpt-4o or gpt-5

Models Supported

gpt-4o gpt-4o-mini gpt-5 gpt-5-mini gpt-4-turbo

Just type the model name in the overlay input. If you don't have GPT-5 access yet, use gpt-4o - it's the best available.

Built for Chrome Console. MIT License. No backend. Key never leaves your browser except to OpenAI.
